# Experiments

Each experiment lives on its own branch and isn't merged into `main` unless it says so. One line each:
what it was, where it lives, how it came out.

- **2026-11-11 · The closed mall** (`fiesta-mall`): Fiesta Mall (Mesa, AZ, 1979–2018) rebuilt at true scale from the OpenStreetMap outline as a two-floor `fiesta` place kind, plus engine support for places bigger than a cell and for two floors. Passes the determinism check; both floors are walkable via escalators. The interior layout is guessed, and every name is invented. Notes: [experiments/fiesta-notes.md](experiments/fiesta-notes.md).
